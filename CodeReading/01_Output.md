# Reading and Modifying simple code - Variables and Output

Read the code and determine what it does.  Then, modify it as instructed.

1. What does the following code do?

```
  int a = 138, b = -56, c = 0;
  Console.WriteLine($"{a} {b} {c}");
```

Modify the code so that each number is on its own line with a label (label it with its variable name).  Make sure to do your modification without adding any lines of code.

Now, modify the code so that each number is output in its own field of 7 digits.  In other words, the numbers will output so that they line up at the least significant digit.  Your output should look like the following:

```
a =     138
b =     -56
c =       0
```

2. What does the following code do?

```
  double x = 1.001, y = -100, z = 3.14;
  Console.WriteLine($"{x} {y} {z}");
```

Modify the code so that each number is on its own line.  Line up the decimal points and ensure that there are 7 digits (or spaces) to the left of the decimal point.  Also, make sure that you output 3 digits after the decimal point.  Your output should look like the following:

```
      1.001
   -100.000
      3.140
```
